# GitHub Release Checklist

- [x] Lightweight readiness scan has no blockers.
- [ ] Contextual private-data review completed.
- [ ] `.gitignore` matches the actual stack/local artifacts.
- [ ] Intended staged diff reviewed.
- [ ] Build/test/lint/type checks run as applicable and results recorded.
- [ ] README/install/usage instructions match actual behavior.
- [ ] Target GitHub owner/repository/branch verified.
- [ ] Visibility and license decisions are intentional when relevant.
- [ ] Release assets/tags/version verified when relevant.
