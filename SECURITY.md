# Security policy

Please do not file public issues containing private Revit files, credentials, or personal data.

For a security concern in this add-in, contact the repository owner privately through GitHub. Include the Revit version, add-in version, and a minimal non-sensitive reproduction.

This add-in does not make network requests and does not collect data. It writes generated RVTs and logs only under the current user's local application-data directory.
